# Sales-Executive-Dashboard-Portfolio_RPOJECT_# 📊 Power BI Data Analytics Portfolio

Welcome to my Power BI portfolio! This repository showcases four projects covering healthcare analytics, hospital patient visits, food delivery sales, and mobile sales analysis.

Through these projects, I have practiced data visualization, KPI reporting, interactive filtering, and business-oriented data exploration using Microsoft Power BI.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power BI Report Visuals
- Interactive Slicers
- KPI Cards
- Data Visualization
- Business Data Analysis

## 📁 Projects

### 1. Healthcare Data Analysis Dashboard

**File:** `Healthcare_Data_Analysis.pbix`

**Overview:**

A healthcare-focused Power BI report containing pages related to admissions and blood data, doctor information, and patient information.

**Key Analysis Areas:**
- Patient and admission information
- Hospital and doctor-related data
- Medical conditions and medications
- Blood type and gender distributions
- Billing amount analysis
- Admission and discharge dates

**Visualizations:**
KPI Cards, Column Charts, Pie Charts, Funnel Charts, Line Charts, Ribbon Charts, Stacked Charts, and Slicers.

**Objective:** Explore healthcare data and present hospital-related information through interactive visualizations.

### 2. Hospital Patient Visit Dashboard

## ▶️ How to Explore the Projects

1. Download the required `.pbix` file.
2. Open Microsoft Power BI Desktop.
3. Open the downloaded report.
4. Review the available report pages and visuals.
5. Use the slicers to explore the data.
6. Review the underlying fields and calculations before drawing conclusions.

If a report uses an external data source, update the data source settings as required.
